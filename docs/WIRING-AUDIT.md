## Fixes shipped during this audit (all live-verified before/after)

1. **BUG-040 wiring gap** — `server/index.js` perception→WS relay dropped every sensor's description (phantom nested `.payload` access). Fixed; `test/server.test.js`'s salience-gate test updated to the real (flat) sensor emission shape it had been silently mismatching.
2. **BUG-045** — `ps-automation.ps1`'s `Handle-ListWindows` had no guard around `AutomationElement` property reads inside its enumeration loop; one stale window handle could fail the whole call. Fixed with a per-window try/catch + skip-and-continue.
3. **BUG-029 (pidfile gap)** — `browser-agent/index.js`'s PID capture for the orphan-cleanup safety net silently failed on the installed Playwright version. Fixed with a `Get-CimInstance`-based fallback (and along the way, caught and fixed a second bug in the fix itself: `execSync` with a shell-string command silently mangled the PowerShell one-liner on Windows — switched to `execFileSync` with an args array, the same pattern `pc-child/index.js` already uses).
4. **3 verify-harness bugs** (BUG-041 UTC/local date mismatch, BUG-014 WS-protocol/new-file detection assumptions, BUG-006 reqId-scoped event collector missing a reqId-less broadcast) — see `BUGS.md`'s own entries for full detail; not re-duplicated here.

## New finding not code-fixed (prompt-behavior, deferred to Phase 5)

**BUG-046** — the voice agent fabricated "PC automation is offline" 3 times in a row for a later utterance in the same live session, with zero corresponding tool-call audit entries (proof it never checked), even though pc-child was genuinely online throughout (proven by continuously successful `media_status` polls in the same window). This is a prompt-honesty gap (mirror image of the already-fixed BUG-007 fabricated-success pattern) — needs a live conversational test alongside any prompt change, per the Phase 5 gate for prompt-level issues.
