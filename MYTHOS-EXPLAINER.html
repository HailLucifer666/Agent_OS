Five-Store Memory

A tiered memory system modeled after human cognition. Data consolidates upward over time.

Working Memory

15-item perception buffer, drained each tick. The entity's present-moment awareness. Holds sensor readings, pending goals, and the current OODA context. Fastest access, shortest retention.

Episodic

Time-series of events with 30-day retention. Every tick's salient observations are recorded with timestamps and salience scores.

Semantic

Consolidated knowledge graph, permanent. High-salience facts distilled from episodic memory by the Brain. Never expires.

Skills

Learned procedures and patterns. Acquired through successful task execution and reflection cycles.

Identity

Persona sections: self.md and boundaries.md define who the entity is and what it must not do.
