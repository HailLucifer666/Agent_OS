**Fix browser-agent launchLocal — `channel` expects string, not array**

File: `mythos/adapters/browser-agent/index.js` line 101-105

**Root cause:** `channel: ['chrome', 'msedge']` passes an array but playwright-core expects a single string. The error is `channel: expected string, got object`.

**Fix:** Replace the single `launchPersistentContext` call with Chrome-first, Edge-fallback:

```js
// Before (broken):
context = await chromium.launchPersistentContext(userDataDir, {
  channel: ['chrome', 'msedge'],
  headless: false,
  viewport: null,
});

// After (try chrome, fall back to msedge):
try {
  context = await chromium.launchPersistentContext(userDataDir, {
    channel: 'chrome', headless: false, viewport: null,
  });
} catch (e1) {
  context = await chromium.launchPersistentContext(userDataDir, {
    channel: 'msedge', headless: false, viewport: null,
  });
}
```

The existing outer catch (line 122) handles the case where both fail. No other changes needed — `mode`, `state`, `launched` assignments after the try block remain unchanged.

**Scope:** Single file, ~4 line change. No test changes (browser-agent has no unit tests, it requires a real browser).
