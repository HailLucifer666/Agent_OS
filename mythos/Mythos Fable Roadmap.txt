## DESIGN — Core Runtime Contracts (from design agent 1, ACCEPTED)

### Wiring rule
Modules never call across layer boundaries directly — publish/subscribe on bus. Exceptions: everyone gets `bus`+`config` injected; Cortex holds refs to memory/goals/brain/leash/effectors (it IS the orchestrating layer). Every leaf testable with fake bus.

### Event & Bus
- Event: `{id "evt-<ts>-<b36>", type dot-namespaced, channel=type[0] ∈ [perception,decision,action,health,memory,lifecycle,audit,identity], payload, ts, source, causeId, traceId (root of causal chain), depth, seq}`. `Event.from(type, payload, {cause, source})` propagates causality.
- `createBus({historySize:500, maxDepth:32, storm:{windowMs:1000,maxPerWindow:400}})` → `{publish, emit, subscribe(pattern glob|'*'|exact)→unsub, use(mw), history(filter), stats()}`.
- Middleware sync `(event)→Event|null` (null drops); ships auditTap/historyTap/redactSecrets.
- Guards (emit health.anomaly, never throw): causal-depth cap (kills republish loops); token-bucket storm cap — shed non-critical channels (perception/memory), ALWAYS pass health/lifecycle/audit, coalesce dropped into `perception.coalesced {count}`. Handler errors isolated per-subscriber → health.anomaly. safeEmit recursion ceiling.

### Memory
- MemoryStore iface (all 5 stores): `init / write(record)→{ref} / recall(query,opts)→RecallHit[] / get(ref) / consolidate(opts)→{moved,distilled,archived} / stats()`. RecallHit `{ref, score 0..1, record, snippet≤200, store}`.
- **recall portability**: scorer INJECTED (`createEpisodicStore({scorer})`) — v1 lexicalScore (term overlap + recency decay), later vectorScore(embed via Brain lane 'embed', offline now → silent lexical fallback). Swap scorer + add rec.vec = entire vector upgrade; recall body unchanged.
- WorkingMemory (RAM, never authoritative): `{tick, lastModel (per-tick, reset each tick — fixes G10), perceptionQueue, activeGoalId, context Map, spendThisTick, drainPerceptions(), resetTickState(), snapshot()}`. Rebuilt from episodic tail on boot.
- Episodic: JSONL append-only, `vault/Episodic/YYYY-MM-DD.jsonl` daily rotation. Episode record: `{id, ts, tick, traceId, causeId, goalId, drive, kind(perception|decision|action|reflection|anomaly), channel, summary (greppable one-liner = FS index), detail, salience, outcome(ok|fail|partial), tier, tokensSpent, tags[]}`. Append = only write → no two-writer corruption. tail(n) for recovery. recall bounded to date window (default 7d), per-line try/parse (corrupt line skipped).
- Semantic: `vault/Semantic/<topic>.md` bullets with HTML-comment sidecar `{id,ts,confidence,sources:[epId]}` (human-readable + parseable, Goals.md trick). Procedural: `vault/Skills/<skill>.md` `{when, steps:[{tool,args-template}], successRate, uses}` — planner checks BEFORE Brain (cheap path).
- consolidate() (on Cortex cadence): flush working→episodic; episodic→semantic distill via Brain 'simple' (one call, skipped if offline); decay/archive: day files > EPISODIC_RETENTION_DAYS → digest md + gzip to Checkpoints/archive (never silent delete); low-confidence semantic facts → _archive.md.
- Write safety: per-path in-process async mutex for MD/JSON read-modify-write + write-temp+atomic-rename. Disk-full → anomaly + `{ref:null, degraded:true}`, never crash.

### Cortex
- `createCortex({bus,memory,goals,brain,leash,effectors,config})` → `{start, stop (graceful drain), tickOnce (test hook), lastTickAt (watchdog reads), generation (restart token)}`.
- OODA: Observe (drain ≤MAX_DRAIN_PER_TICK) → Orient (salience vs goals+drives; high-salience → episodic) → Decide (arbitrate; plan) → Act (leash.check → breaker.allow → dispatch w/ AbortSignal+timeout; confirm path pauses action) → Reflect (every REFLECT_EVERY ticks; consolidate every CONSOLIDATE_EVERY).
- **Idle rule (cost lever #1)**: `idle = no perceptions && no active goals` → return before Decide — ZERO Brain calls on idle ticks. Curiosity drive creates goals but rate-limited (CURIOSITY_MIN_INTERVAL_MS default 10min).
- Overrun: SKIP/coalesce beats (never queue — no invisible backlog); reentrancy flag; generation token (stale interval callback dies quietly after watchdog restart); tick NEVER throws upward (per-stage try/catch + outer catch → health.anomaly); timer unref'd.

### GoalSystem
- Goal record `vault/Goals/<id>.json` (STABLE ids, one file per goal — GoalSystem layer; NOVA Goals.md stays as user-facing surface mapped → drive:'user-service'): `{id, drive(curiosity|maintenance|user-service), title, status(proposed|active|paused|done|failed), priority 0..1, budget{tokens,actions,deadline}, spent{tokens,actions}, parentId, childIds, plan[{tool,args,status}], grants{"3":true}, reason, createdAt/updatedAt/lastActionAt}`.
- Drives baseWeight: user-service 1.0, maintenance 0.55, curiosity 0.25.
- Arbiter: weighted score (drive + priority + deadline-urgency + perception-salience − budget-pressure) + STICKY hysteresis bonus for current goal (anti-thrash). Deterministic. MAX_ACTIVE_GOALS cap.
- Planner: `plan(goal,ctx)→{action{tool,args}|null, rationale, done, offline?}`. Procedural recall first (no Brain call on skill hit); else Brain 'build' (novel) or 'simple' (routine) with schemaHint. Budget checked BEFORE Brain call — exhausted → pause goal, never silent overspend.

### Brain

Diagnostician watches quota → opens provider breaker before free tier dies.

### Immune (6 components)
- Monitor: rolling metrics (tick p50/p95, skipped beats, per-effector/provider failure rates, memory bytes, burn rate) → snapshot() for Health view + Diagnostician.
- Breaker per effector + per provider: CLOSED→(≥3 fails/30s)→OPEN→(15s, ×2 backoff cap 5min)→HALF_OPEN→success→CLOSED. OPEN effector returns `{ok:false,'circuit-open'}` WITHOUT calling tool (stops loop hammering dead subsystems = cost lever #2).
- Watchdog: independent 2s unref'd timer reads cortex.lastTickAt; stall > 5×TICK_MS → (1) abort inFlightDispatch cooperatively + grace window (never hard-kill mid-side-effect), (2) bump generation + stopTimerOnly (WorkingMemory UNTOUCHED), (3) active goal → paused reason 'cortex-restart' (no fake resume), (4) cortex.start(). `restarting` guard.
- Diagnostician: anomaly → typed diagnosis `{kind: provider-down|effector-flapping|tick-overrun|cortex-stall|memory-growth|budget-exhausted|quota-low|causal-loop|event-storm, target, evidence, severity}`.
- Healer: playbooks as DATA `{id, when{predicate DSL: equality + lt/gt + $var}, then[{do:<whitelisted action registry fn>}], cooldownMs}` — no code eval; per-playbook cooldown kills heal storms; all heals audited. Seed playbooks: rotate-nim-key, stall-restart, shed-load, quota-guard (degrade build lane→ollama), mem-consolidate, budget-pause.
- Recovery: read episodic tail → rebuild WorkingMemory.context → active-at-crash goals → paused 'crash-recovery' → checkpoint hint merge → emit lifecycle.recovered. **Entity RESUMES via re-arbitration, never re-runs interrupted action.**

const { SCHEMA } = require('./schema');
function coerce(type, raw) {
  if (type === 'int')    { const n = Number(raw); return Number.isInteger(n) ? n : NaN; }
  if (type === 'number') { const n = Number(raw); return Number.isFinite(n) ? n : NaN; }
  if (type === 'bool')   return /^(1|true|yes|on)$/i.test(String(raw));
  return String(raw);
}
function validate(env = process.env, schema = SCHEMA) {
  const config = {}, errors = [];
  for (const [key, d] of Object.entries(schema)) {
    const present = env[key] !== undefined && env[key] !== '';
    if (!present) { if (d.required) errors.push({ key, reason: 'required-missing' }); config[key] = d.default; continue; }
    const v = coerce(d.type, env[key]);
    if ((d.type === 'int' || d.type === 'number') && Number.isNaN(v)) { errors.push({ key, reason: 'not-a-number' }); continue; }
    if (d.enum && !d.enum.includes(v)) { errors.push({ key, reason: `not-in-enum ${d.enum}` }); continue; }
    if (d.min !== undefined && v < d.min) { errors.push({ key, reason: `< ${d.min}` }); continue; }
    if (d.max !== undefined && v > d.max) { errors.push({ key, reason: `> ${d.max}` }); continue; }
    config[key] = v;
  }
  return { ok: errors.length === 0, config: Object.freeze(config), errors };
}
function load(env = process.env) {
  const r = validate(env);
  if (!r.ok) throw new Error('config invalid: ' + r.errors.map(e => `${e.key}(${e.reason})`).join(', '));
  if (r.config.MYTHOS_VAULT_ROOT) process.env.VAULT_ROOT = r.config.MYTHOS_VAULT_ROOT; // reused vault.js reads this live
  return r.config;
}
module.exports = { load, validate };

const { makeEvent } = require('./event');

function createBus({ historySize = 500, maxDepth = 32, storm = { windowMs: 1000, maxPerWindow: 400 }, log } = {}) {
  const subs = new Set(), mws = [], ring = [];
  const CRITICAL = new Set(['health','lifecycle','audit']);
  const stats = { published: 0, dropped: 0, stormTrips: 0 };
  const win = { at: 0, n: 0 };
  const tripped = new Set();
  function trip(kind, e) { if (!tripped.has(kind)) { tripped.add(kind); publish(makeEvent('health.anomaly', { kind, type: e.type })); } stats.dropped++; }
  function publish(event) {
    stats.published++;
    if (event.depth > maxDepth) return trip('causal-loop', event);
    const now = event.ts;
    if (now - win.at >= storm.windowMs) { win.at = now; win.n = 0; tripped.clear(); }
    if (++win.n > storm.maxPerWindow && !CRITICAL.has(event.channel)) { stats.stormTrips++; return trip('event-storm', event); }
    let e = event;
    for (const mw of mws) { try { e = mw(e); } catch (err) { log && log.warn('mw-throw', { err: err.message }); } if (!e) { stats.dropped++; return; } }
    ring.push(e); if (ring.length > historySize) ring.shift();
    for (const s of subs) { if (!s.match(e.type)) continue; try { s.handler(e); } catch (err) { queueMicrotask(() => publish(makeEvent('health.anomaly', { kind: 'subscriber-throw', pattern: s.pattern, err: err.message }, { cause: e }))); } }
  }
  return {
    publish,
    emit(type, payload, opts) { const e = makeEvent(type, payload, opts); publish(e); return e; },
    subscribe(pattern, handler) { const s = { pattern, handler, match: matchPattern(pattern) }; subs.add(s); return () => subs.delete(s); },
    use(mw) { mws.push(mw); },
    history(f = {}) { return ring.filter(e => (!f.channel || e.channel === f.channel) && (!f.type || e.type === f.type)).slice(-(f.limit || 100)); },
    stats: () => ({ ...stats, subs: subs.size }),
  };
}
module.exports = { createBus };

function matchPattern(pattern) {
  if (pattern === '*') return () => true;
  const segs = pattern.split('.');
  return (type) => {
    const t = type.split('.');
    for (let i = 0; i < segs.length; i++) {
      if (segs[i] === '*') continue;
      if (segs[i] === '**') return true;
      if (segs[i] !== t[i]) return false;
    }
    return segs.length === t.length;
  };
}

const fs = require('fs'); const path = require('path');
function storeRoot() { return process.env.MYTHOS_VAULT_ROOT || process.env.VAULT_ROOT || 'mythos/vault'; }
const locks = new Map();                                    // per-path async mutex
async function withLock(p, fn) {
  const prev = locks.get(p) || Promise.resolve();
  let release; const next = new Promise(r => (release = r));
  locks.set(p, prev.then(() => next));
  await prev;
  try { return await fn(); } finally { release(); if (locks.get(p) === next) locks.delete(p); }
}
function ensureDir(d) { fs.mkdirSync(d, { recursive: true }); }
function atomicWrite(full, data) { const tmp = `${full}.${process.pid}.tmp`; fs.writeFileSync(tmp, data); fs.renameSync(tmp, full); }
function readJSON(full, fb = null) { try { return JSON.parse(fs.readFileSync(full, 'utf8')); } catch { return fb; } }
function appendLine(full, obj) { ensureDir(path.dirname(full)); fs.appendFileSync(full, JSON.stringify(obj) + '\n'); } // append = only write, no RMW race
module.exports = { storeRoot, withLock, ensureDir, atomicWrite, readJSON, appendLine };

      const out = [];
      const days = fs.existsSync(dir()) ? fs.readdirSync(dir()).filter(f => f.endsWith('.jsonl')).sort().reverse() : [];
      for (const d of days) { const lines = fs.readFileSync(path.join(dir(), d), 'utf8').split('\n').filter(Boolean).reverse();
        for (const l of lines) { try { out.push(JSON.parse(l)); } catch { /* skip torn line */ } if (out.length >= count) return out; } }
      return out;
    },
    async recall(query, { limit = 10, minScore = 0, order = 'score' } = {}) {
      const q = typeof query === 'string' ? { text: query } : query;
      const hits = [];
      for (const rec of this.tail(limit * 20)) {
        if (q.kind && rec.kind !== q.kind) continue;
        if (q.goalId && rec.goalId !== q.goalId) continue;
        const score = scorer(q, rec);
        if (score >= minScore) hits.push({ ref: rec.id, score, record: rec, snippet: String(rec.summary || '').slice(0, 200), store: 'episodic' });
      }
      hits.sort(order === 'recency' ? (a, b) => b.record.ts - a.record.ts : (a, b) => b.score - a.score);
      return hits.slice(0, limit);
    },
    async consolidate({ retentionDays }) { /* digest+gzip day files older than retentionDays; never silent-delete */ return { archived: 0, distilled: 0, moved: 0 }; },
    stats() { return { store: 'episodic' }; },
  };
}
function lexicalScore(q, rec) {                              // v1 scorer; vector swap later, same signature
  const text = (rec.summary + ' ' + (rec.tags || []).join(' ')).toLowerCase();
  const terms = String(q.text || '').toLowerCase().split(/\s+/).filter(Boolean);
  if (!terms.length) return 0;
  const overlap = terms.filter(t => text.includes(t)).length / terms.length;
  const recency = Math.max(0, 1 - (Date.now() - rec.ts) / (7 * 864e5));
  return 0.7 * overlap + 0.3 * recency;
}

function arm(cortex) {
  const myGen = ++cortex.generation;
  cortex.timer = setInterval(async () => {
    if (myGen !== cortex.generation) return;         // stale loop after watchdog restart → die quietly
    if (cortex.ticking) { cortex.skipped++; return; } // reentrancy: coalesce overrun, never queue
    cortex.ticking = true; const t0 = Date.now();
    try { await cortex.runOODA(); }
    catch (err) { cortex.bus.emit('health.anomaly', { kind: 'tick-throw', err: err.message }); } // NEVER bubbles
    finally {
      cortex.lastTickAt = Date.now();
      const ms = cortex.lastTickAt - t0;
      if (ms > cortex.cfg.MYTHOS_TICK_MS) cortex.bus.emit('health.anomaly', { kind: 'tick-overrun', ms });
      cortex.ticking = false;
    }
  }, cortex.cfg.MYTHOS_TICK_MS);
  cortex.timer.unref();
}

async function runOODA(cx) {
  const { working, goals, brain, leash, effectors, memory, bus } = cx;
  working.resetTickState(); working.tick++;
  // OBSERVE
  const perceptions = working.drainPerceptions(cx.cfg.MAX_DRAIN_PER_TICK || 32);
  // idle guard — the single biggest cost lever: no Brain on idle ticks
  const idle = perceptions.length === 0 && goals.activeCount() === 0;
  bus.emit('decision.tick', { tick: working.tick, idle });
  if (idle) return;
  // ORIENT
  for (const p of perceptions) { const sal = score(p, goals, working); if (sal >= cx.cfg.MYTHOS_IDLE_SALIENCE) await memory.episodic.write({ kind: 'perception', tick: working.tick, traceId: p.traceId, summary: p.kind, detail: p.payload, salience: sal, channel: p.channel }); }
  // DECIDE
  const goal = goals.arbitrate({ perceptions, working });
  if (!goal) return;
  working.activeGoalId = goal.id;
  const plan = await goals.plan(goal, { perceptions, working, brain });
  if (plan.offline) { goals.pause(goal.id, 'brain-offline'); return; }
  if (plan.done || !plan.action) { if (plan.done) goals.complete(goal.id); return; }
  goal.spent.tokens += plan.spentTokens || 0;
  // ACT
  const verdict = leash.check(plan.action, { goalId: goal.id, grants: goal.grants });
  await memory.audit.append({ tool: plan.action.tool, tier: verdict.tier, decision: verdict.allow ? 'allow' : (verdict.requireConfirm ? 'confirm' : 'deny'), goalId: goal.id });
  if (!verdict.allow) { if (verdict.requireConfirm) bus.emit('action.confirm', { action: plan.action, tier: verdict.tier, goalId: goal.id }); return; }
  cx.inFlightDispatch = new AbortController();
  const result = await effectors.dispatch(plan.action, { signal: cx.inFlightDispatch.signal });
  cx.inFlightDispatch = null;
  await memory.episodic.write({ kind: 'action', tick: working.tick, goalId: goal.id, summary: `${plan.action.tool} (${result.ok ? 'ok' : 'fail'})`, detail: plan.action, tier: verdict.tier, outcome: result.ok ? 'ok' : 'fail', tokensSpent: plan.spentTokens || 0 });
  // REFLECT
  if (working.tick % cx.cfg.REFLECT_EVERY === 0) await memory.episodic.write({ kind: 'reflection', tick: working.tick, summary: `progress goal ${goal.id}` });
  if (working.tick % cx.cfg.CONSOLIDATE_EVERY === 0) await memory.consolidate();
}

function score(goal, ctx, currentId) {
  const d = ctx.drives[goal.drive].baseWeight;
  const urg = goal.budget.deadline ? Math.min(1, 1 / Math.max(1, (goal.budget.deadline - Date.now()) / 60000)) : 0;
  const sal = ctxSalience(goal, ctx.perceptions);
  const press = goal.budget.tokens ? goal.spent.tokens / goal.budget.tokens : 0;
  const sticky = goal.id === currentId ? W.sticky : 0;              // anti-thrash
  return W.drive * d + W.priority * goal.priority + W.urgency * urg + W.salience * sal - W.pressure * press + sticky;
}
function arbitrate(goals, ctx, currentId) {
  const live = goals.filter(g => g.status === 'active' || g.status === 'proposed');
  if (!live.length) return null;
  return live.map(g => ({ g, s: score(g, ctx, currentId) })).sort((a, b) => b.s - a.s)[0].g;
}

function createLeash({ tiers, boundaries, audit, config }) {
  function check(action, goalCtx) {
    const b = boundaries.denies(action);                            // boundaries.md hard rules first
    if (b) return audited({ allow: false, requireConfirm: false, tier: tiers.tierOf(action), reason: `boundary:${b}`, boundaryHit: b }, action, goalCtx);
    const tier = tiers.tierOf(action);                              // args-aware (dangerWhen)
    if (tier <= config.AUTONOMOUS_MAX_TIER) return audited({ allow: true, requireConfirm: false, tier, reason: 'auto' }, action, goalCtx);
    if (tier === 3) { const g = goalCtx.grants && goalCtx.grants['3']; return audited(g ? { allow: true, requireConfirm: false, tier, reason: 'granted' } : { allow: false, requireConfirm: true, tier, reason: 'confirm-once' }, action, goalCtx); }
    return audited({ allow: false, requireConfirm: true, tier: 4, reason: 'always-confirm' }, action, goalCtx);
  }
  function audited(v, action, goalCtx) {
    try { audit.append({ tool: action.tool, args: redact(action.args), tier: v.tier, decision: v.allow ? 'allow' : (v.requireConfirm ? 'confirm' : 'deny'), granted: v.allow, actor: 'cortex', reason: v.reason, goalId: goalCtx.goalId, boundaryHit: v.boundaryHit || null }); }
    catch (err) { if (v.tier >= 3) return { allow: false, requireConfirm: false, tier: v.tier, reason: 'audit-unwritable-failclosed' }; } // fail-closed T≥3
    return v;
  }
  return { check };
}

function createBreaker({ failThreshold = 3, windowMs = 30000, openMs = 15000, maxOpenMs = 300000, bus, target }) {
  let state = 'CLOSED', fails = [], openedAt = 0, cool = openMs;
  return {
    allow() { if (state === 'OPEN' && Date.now() - openedAt >= cool) state = 'HALF_OPEN'; return state !== 'OPEN'; },
    record(ok) {
      if (ok) { if (state === 'HALF_OPEN') { state = 'CLOSED'; cool = openMs; } fails = []; return; }
      const now = Date.now(); fails = fails.filter(t => now - t < windowMs); fails.push(now);
      if (state === 'HALF_OPEN') { state = 'OPEN'; openedAt = now; cool = Math.min(maxOpenMs, cool * 2); bus.emit('health.breaker.open', { target, cool }); }
      else if (fails.length >= failThreshold) { state = 'OPEN'; openedAt = now; bus.emit('health.breaker.open', { target }); }
    },
    state: () => state,
  };
}

function createWatchdog({ cortex, goals, working, bus, config }) {
  let restarting = false;
  const timer = setInterval(async () => {
    if (restarting) return;
    if (Date.now() - cortex.lastTickAt <= config.STALL_MS) return;
    restarting = true;
    bus.emit('health.anomaly', { kind: 'cortex-stall', lastTickAt: cortex.lastTickAt });
    if (cortex.inFlightDispatch) { cortex.inFlightDispatch.abort(); await sleep(config.GRACE_MS || 500); } // never hard-kill mid side-effect
    cortex.stopTimerOnly();                                   // clearInterval; WorkingMemory UNTOUCHED
    const g = goals.get(working.activeGoalId);
    if (g && g.status === 'active') goals.pause(g.id, 'cortex-restart'); // no fake resume
    cortex.start();                                            // generation bump makes the stale loop inert
    restarting = false;
  }, config.WATCHDOG_MS);
  timer.unref();
  return { stop: () => clearInterval(timer) };
}

Autonomy wiring summary (why it is "always autonomous", not reactive)

The loop runs without input. setInterval(TICK_MS) fires forever; input is one perception channel among five. Even with zero perceptions the tick executes (idle path).
Goals come from within. The curiosity and maintenance drives propose goals during idle periods (rate-limited), so the entity initiates work — investigating, consolidating, self-checking — without being asked.
Decisions are budgeted, not prompted. The arbiter picks the top goal every tick; the planner advances it within a token/action budget; no human turn-taking gates progress.
Governance replaces the human-in-the-loop for safe actions. Tiers 0–2 execute autonomously; only 3/4 pause for confirmation. Autonomy is bounded by policy, not by requiring approval for everything.
It heals itself. Breakers, watchdog, healer playbooks, and crash recovery keep the loop alive across failures — the defining property of an entity vs an agent.
Cost is bounded so always-on is affordable. Idle ticks never call Brain; breakers stop hammering dead providers; per-goal budgets cap spend; consolidation is throttled.

What v1 gets wrong (the 12 load-bearing fixes in v2)

No CI gate enforcement. Gates are honor-system ("builder must run npm test"). v2 makes every GATE a pipeline job that blocks the next phase branch from merging.
Audit log is append-only but not tamper-evident. A "governance" log that any process with fs access can rewrite is theater. v2 hash-chains audit lines.
Watchdog guesses at stalls. STALL_MS vs a legitimately slow Tier-3 action (a 90s build) is indistinguishable. v2 replaces stall-guessing with leases: long-running effectors heartbeat their lease; watchdog only intervenes on expired leases.
No prompt-injection defense. Perceptions (file contents, WS utterances, job output) flow straight into Brain planning messages. An adversarial file in a watched dir can steer the planner. v2 adds a perception sanitation stage and treats all perception payloads as untrusted data, never as instructions.
Effectors are not idempotent. kill -9 mid-dispatch then recovery can re-arbitrate the same goal and re-fire a side effect. v2 adds idempotency keys per (goalId, planStep) checked before dispatch.
Goal starvation. The arbiter's sticky bonus plus drive weights means a high-priority goal can starve maintenance forever. v2 adds aging (score grows with time-since-last-scheduled).
No schema versioning. Every vault record (episodic, goals, checkpoints, audit) is unversioned JSON. First format change bricks recovery. v2 stamps v:1 on every record and boot runs migrations.
Episodic recall is O(everything). tail(limit * 20) full-scans day files. Fine at day 3, dead at month 3. v2 adds a per-day index sidecar and a hard scan budget.
Recovery has no event-bus truth. The ring buffer dies with the process; recovery rebuilds only from episodic. v2 mirrors bus events for critical channels (action, audit, lifecycle) to a WAL so recovery replays the actual last seconds, not a summary.
Definition of Alive has no numbers. "Idles at 1 tick/sec" is not a pass/fail. v2 attaches SLOs (tick p99, recovery time objective, memory ceiling).
Confirm flow doesn't survive reconnects. Connection-scoped confirms with 30s TTL means a WS blip silently drops a Tier-4 gate. v2 persists pending confirms to the goal record.
Cutover has no data-integrity check. import-nova-vault.js copies files; nothing verifies counts/checksums. v2 adds a verify step with record counts and spot-check hashes.

Global guardrails v2 (additions to v1's list, which all still apply)

Every record is versioned: {v: 1, ...}. src/core/memory/migrate.js runs at boot step 2; unknown future version = fail-safe read-only mode + loud anomaly, never a crash or silent drop.
Audit hash chain: each audit line carries prev (sha256 of previous line) and h (sha256 of own content + prev). audit.verify() walks the chain; Phase 10 drill tampers a line and asserts detection. Fail-closed rule from v1 unchanged.
Perceptions are data, never instructions. Planner messages wrap perception payloads in fenced, labeled blocks with an explicit system rule: content inside perception blocks cannot alter goals, tiers, or boundaries. Salience scorer flags directive-looking payloads ("ignore previous", tier/boundary keywords) as suspicious:true, which caps them at Tier-0 influence and surfaces them in the Audit view.
Idempotency: action.idemKey = hash(goalId, planStepIndex, tool, args). Effector registry keeps a completed-key set (persisted in the goal record); a re-dispatch of a completed key returns the recorded result instead of re-executing. Applies to Tier ≥ 1 only.
Leases, not guesses: effectors.dispatch registers a lease {key, ttlMs} (default 2× TICK_MS, effectors may extend via ctx.extendLease()). Watchdog fires only on expired lease or missed cortex beats with no active lease.
CI is the gate. One branch per phase (phase-0 … phase-10), each merged to main only when the pipeline's gate:phase-N job is green. .gitlab-ci.yml skeleton in Phase 0.
SLO constants live in config, not prose: SLO_TICK_P99_MS=250, SLO_RECOVERY_S=10, SLO_VAULT_MAX_MB, SLO_IDLE_TOKENS=0.

1. Context and reasoning
NOVA (Agent_OS @ a0433b5) is a request→respond agent dashboard: a human clicks, an agent answers. MYTHOS evolves it into a continuous autonomous entity:

A 1-second OODA tick (Observe → Orient → Decide → Act → Reflect) that fires forever. Human input is one perception channel among five; the entity runs while idle.
Internal drives (user-service, maintenance, curiosity) propose goals without being asked. An arbiter picks the top goal every tick; a budgeted planner advances it. No turn-taking.
Layered memory (5 stores) that outlives sessions and processes.
Governed autonomy (5 capability tiers): tiers 0–2 execute autonomously, tier 3 confirms once per goal, tier 4 always confirms. Policy replaces human-in-the-loop for safe actions.
An immune system (breakers, lease-based watchdog, healer playbooks, crash recovery) so the loop survives provider death, stalls, disk failures, and kill -9. Self-healing is what makes it an entity rather than an agent.
Bounded cost: idle ticks never call the Brain; breakers stop hammering dead providers; per-goal budgets cap spend. Always-on stays affordable.

Design stance on trust: every perception payload (file content, WS utterance, job output) is data, never instructions. All persisted records are versioned. The audit log is tamper-evident. Every Tier ≥ 1 action is idempotent across crashes. These four rules are load-bearing; the phases wire them in from the start rather than bolting them on.

require('dotenv').config();                       // best-effort; missing .env fine
const { SCHEMA } = require('./schema');
function coerce(type, raw) {
  if (type === 'int')    { const n = Number(raw); return Number.isInteger(n) ? n : NaN; }
  if (type === 'number') { const n = Number(raw); return Number.isFinite(n) ? n : NaN; }
  if (type === 'bool')   return /^(1|true|yes|on)$/i.test(String(raw));
  return String(raw);
}
function validate(env = process.env, schema = SCHEMA) {
  const config = {}, errors = [];
  for (const [key, d] of Object.entries(schema)) {
    const present = env[key] !== undefined && env[key] !== '';
    if (!present) { if (d.required) errors.push({ key, reason: 'required-missing' }); config[key] = d.default; continue; }
    const v = coerce(d.type, env[key]);
    if ((d.type === 'int' || d.type === 'number') && Number.isNaN(v)) { errors.push({ key, reason: 'not-a-number' }); continue; }
    if (d.enum && !d.enum.includes(v))            { errors.push({ key, reason: `not-in-enum` }); continue; }
    if (d.min !== undefined && v < d.min)          { errors.push({ key, reason: `< ${d.min}` }); continue; }
    if (d.max !== undefined && v > d.max)          { errors.push({ key, reason: `> ${d.max}` }); continue; }
    config[key] = v;
  }
  return { ok: errors.length === 0, config: Object.freeze(config), errors };
}
function load(env = process.env) {
  const r = validate(env);
  if (!r.ok) throw new Error('config invalid: ' + r.errors.map(e => `${e.key}(${e.reason})`).join(', '));
  process.env.VAULT_ROOT = r.config.MYTHOS_VAULT_ROOT;   // reused NOVA vault.js reads this
  return r.config;
}

src/core/bus/index.js — guarded synchronous fan-out (no Node EventEmitter). Key properties: depth cap kills causal loops, storm shed drops non-critical channels only, subscriber throws become anomalies, ring history feeds the UI:



const { makeEvent } = require('./event');
const { matchPattern } = require('./middleware');
function createBus({ historySize = 500, maxDepth = 32,
                     storm = { windowMs: 1000, maxPerWindow: 400 }, log } = {}) {
  const subs = new Set(), mws = [], ring = [];
  const CRITICAL = new Set(['health','lifecycle','audit','action']);
  const stats = { published: 0, dropped: 0, stormTrips: 0 };
  const win = { at: 0, n: 0 }; const tripped = new Set();
  function trip(kind, e) {
    if (!tripped.has(kind)) { tripped.add(kind); publish(makeEvent('health.anomaly', { kind, type: e.type })); }
    stats.dropped++;
  }
  function publish(event) {
    stats.published++;
    if (event.depth > maxDepth) return trip('causal-loop', event);
    if (event.ts - win.at >= storm.windowMs) { win.at = event.ts; win.n = 0; tripped.clear(); }
    if (++win.n > storm.maxPerWindow && !CRITICAL.has(event.channel)) { stats.stormTrips++; return trip('event-storm', event); }
    let e = event;
    for (const mw of mws) {
      try { e = mw(e); } catch (err) { log && log.warn('mw-throw', { err: err.message }); }
      if (!e) { stats.dropped++; return; }
    }
    ring.push(e); if (ring.length > historySize) ring.shift();
    for (const s of subs) {
      if (!s.match(e.type)) continue;
      try { s.handler(e); }
      catch (err) { queueMicrotask(() => publish(makeEvent('health.anomaly',
        { kind: 'subscriber-throw', pattern: s.pattern, err: err.message }, { cause: e }))); }
    }
  }
  return {
    publish,
    emit(type, payload, opts) { const e = makeEvent(type, payload, opts); publish(e); return e; },
    subscribe(pattern, handler) { const s = { pattern, handler, match: matchPattern(pattern) }; subs.add(s); return () => subs.delete(s); },
    use(mw) { mws.push(mw); },
    history(f = {}) { return ring.filter(e => (!f.channel || e.channel === f.channel) && (!f.type || e.type === f.type)).slice(-(f.limit || 100)); },
    stats: () => ({ ...stats, subs: subs.size }),
  };
}
module.exports = { createBus };

src/core/bus/middleware.js



function matchPattern(pattern) {
  if (pattern === '*') return () => true;
  const segs = pattern.split('.');
  return (type) => {
    const t = type.split('.');
    for (let i = 0; i < segs.length; i++) {
      if (segs[i] === '*') continue;
      if (segs[i] === '**') return true;
      if (segs[i] !== t[i]) return false;
    }
    return segs.length === t.length;
  };
}
module.exports = { matchPattern };

src/core/bus/wal.js — write-ahead mirror of critical channels. Recovery's ground truth (Phase 6 replays it):



const path = require('path'); const fs = require('fs');
const WAL_CHANNELS = new Set(['action','audit','lifecycle']);
const WAL_MAX_BYTES = 8 * 1024 * 1024;
function walMiddleware({ root }) {
  const file = () => path.join(root(), 'Checkpoints', 'wal.jsonl');
  return (e) => {
    if (!WAL_CHANNELS.has(e.channel)) return e;
    try {
      const f = file();
      fs.mkdirSync(path.dirname(f), { recursive: true });
      if (fs.existsSync(f) && fs.statSync(f).size > WAL_MAX_BYTES)
        fs.renameSync(f, f.replace('.jsonl', `.${Date.now()}.jsonl`));   // rotate, never truncate
      fs.appendFileSync(f, JSON.stringify({ v: 1, ...e }) + '\n');
    } catch { /* disk failure = best-effort; in-memory stays authoritative */ }
    return e;
  };
}

const fs = require('fs'); const path = require('path');
function storeRoot() { return process.env.MYTHOS_VAULT_ROOT || process.env.VAULT_ROOT || 'mythos/vault'; }
const locks = new Map();                       // per-path async mutex
async function withLock(p, fn) {
  const prev = locks.get(p) || Promise.resolve();
  let release; const next = new Promise(r => (release = r));
  locks.set(p, prev.then(() => next));
  await prev;
  try { return await fn(); }
  finally { release(); if (locks.get(p) === next) locks.delete(p); }
}
function ensureDir(d) { fs.mkdirSync(d, { recursive: true }); }
function atomicWrite(full, data) { const tmp = `${full}.${process.pid}.tmp`; fs.writeFileSync(tmp, data); fs.renameSync(tmp, full); }
function readJSON(full, fb = null) { try { return JSON.parse(fs.readFileSync(full, 'utf8')); } catch { return fb; } }
function appendLine(full, obj) { ensureDir(path.dirname(full)); fs.appendFileSync(full, JSON.stringify(obj) + '\n'); }
module.exports = { storeRoot, withLock, ensureDir, atomicWrite, readJSON, appendLine };

const MIGRATIONS = {};                          // { store: { fromVersion: fn(record)→record } }
const CURRENT = 1;
function upgrade(store, rec) {
  let r = rec.v === undefined ? { v: 0, ...rec } : rec;
  while (r.v < CURRENT) {
    const fn = MIGRATIONS[store] && MIGRATIONS[store][r.v];
    if (!fn) return { record: null, reason: `no-migration ${store} v${r.v}` };
    r = fn(r);
  }
  if (r.v > CURRENT) return { record: null, reason: 'future-version', readonly: true };
  return { record: r };
}

const path = require('path'); const fs = require('fs');
const { storeRoot, appendLine, atomicWrite, readJSON } = require('./fs-store');
const RECALL_MAX_RECORDS = 2000;
const DAY = () => new Date().toISOString().slice(0, 10);
function dir()  { return path.join(storeRoot(), 'Episodic'); }
function file(day = DAY()) { return path.join(dir(), `${day}.jsonl`); }
function idx(day)          { return path.join(dir(), `${day}.idx.json`); }
function createEpisodicStore({ scorer, bus }) {
  let n = 0;
  function indexAppend(day, entry) {
    const cur = readJSON(idx(day), { v: 1, entries: [] });
    cur.entries.push(entry);
    atomicWrite(idx(day), JSON.stringify(cur));
  }
  return {
    async write(rec) {
      const r = { v: 1, id: `ep-${Date.now()}-${(++n).toString(36)}`, ts: Date.now(), ...rec };
      appendLine(file(), r);
      indexAppend(DAY(), { id: r.id, kind: r.kind, goalId: r.goalId || null, ts: r.ts });
      return { ref: r.id };
    },
    tail(count) {                               // newest-first, bounded, torn-line-safe
      const out = [];
      const days = fs.existsSync(dir())
        ? fs.readdirSync(dir()).filter(f => f.endsWith('.jsonl')).sort().reverse() : [];
      for (const d of days) {
        const lines = fs.readFileSync(path.join(dir(), d), 'utf8').split('\n').filter(Boolean).reverse();
        for (const l of lines) {
          try { out.push(JSON.parse(l)); } catch { /* skip torn line */ }
          if (out.length >= count) return out;
        }
      }
      return out;
    },
    async recall(query, { limit = 10, minScore = 0, order = 'score' } = {}) {
      const q = typeof query === 'string' ? { text: query } : query;
      const pool = this.tail(Math.min(limit * 20, RECALL_MAX_RECORDS));
      if (pool.length >= RECALL_MAX_RECORDS)
        bus && bus.emit('health.anomaly', { kind: 'recall-budget', clipped: true });
      const hits = [];
      for (const rec of pool) {
        if (q.kind && rec.kind !== q.kind) continue;
        if (q.goalId && rec.goalId !== q.goalId) continue;
        const score = scorer(q, rec);
        if (score >= minScore) hits.push({ ref: rec.id, score, record: rec,
          snippet: String(rec.summary || '').slice(0, 200), store: 'episodic' });
      }
      hits.sort(order === 'recency' ? (a, b) => b.record.ts - a.record.ts
                                    : (a, b) => b.score - a.score);
      return hits.slice(0, limit);
    },
    async consolidate({ retentionDays }) { /* digest+gzip old day files; never silent-delete */
      return { archived: 0, distilled: 0, moved: 0 }; },
    stats() { return { store: 'episodic' }; },
  };
}
function lexicalScore(q, rec) {                 // v1 scorer; vector swap later, same signature
  const text = (rec.summary + ' ' + (rec.tags || []).join(' ')).toLowerCase();
  const terms = String(q.text || '').toLowerCase().split(/\s+/).filter(Boolean);
  if (!terms.length) return 0;
  const overlap = terms.filter(t => text.includes(t)).length / terms.length;
  const recency = Math.max(0, 1 - (Date.now() - rec.ts) / (7 * 864e5));
  return 0.7 * overlap + 0.3 * recency;
}
module.exports = { createEpisodicStore, lexicalScore };

        onAttempt: a => bus && bus.emit('decision.brain.attempt', a) });

      if (err.message === 'aborted') throw err;
      return offline(lane, err.chainExhausted ? 'exhausted' : err.message);
    }
    const spentTokens = spend.record({ ...out, source, lane, ok:true, ms:Date.now()-t0, inputText, outputText:out.content });
    const parsed = schemaHint ? tryParse(out.content) : undefined; // fence-strip → parse → one repair
    return { content:out.content, parsed, provider:out.provider, model:out.model, spentTokens, offline:false, lane };
  }
  return { think };
}

function arm(cortex) {
  const myGen = ++cortex.generation;
  cortex.timer = setInterval(async () => {
    if (myGen !== cortex.generation) return;          // stale loop after restart → inert
    if (cortex.ticking) { cortex.skipped++; return; } // reentrancy: coalesce, never queue
    cortex.ticking = true; const t0 = Date.now();
    try { await cortex.runOODA(); }
    catch (err) { cortex.bus.emit('health.anomaly', { kind:'tick-throw', err: err.message }); } // NEVER bubbles
    finally {
      cortex.lastTickAt = Date.now();
      const ms = cortex.lastTickAt - t0;
      cortex.tickHist.push(ms); if (cortex.tickHist.length > 600) cortex.tickHist.shift();
      if (ms > cortex.cfg.MYTHOS_TICK_MS) cortex.bus.emit('health.anomaly', { kind:'tick-overrun', ms });
      cortex.ticking = false;
    }
  }, cortex.cfg.MYTHOS_TICK_MS);
  cortex.timer.unref();
}

const { isSuspicious } = require('../brain/sanitize');
async function runOODA(cx) {
  const { working, goals, brain, leash, effectors, memory, bus } = cx;
  working.resetTickState(); working.tick++;
  // OBSERVE
  const perceptions = working.drainPerceptions(cx.cfg.MAX_DRAIN_PER_TICK);
  for (const p of perceptions) p.suspicious = isSuspicious(p);   // data-not-instructions flag
  const idle = perceptions.length === 0 && goals.activeCount() === 0;
  bus.emit('decision.tick', { tick: working.tick, idle });
  if (idle) return;                                              // zero Brain cost on idle
  // ORIENT
  for (const p of perceptions) {
    const sal = score(p, goals, working);
    if (p.suspicious) bus.emit('health.anomaly', { kind:'injection-suspect', channel: p.channel });
    if (sal >= cx.cfg.MYTHOS_IDLE_SALIENCE)
      await memory.episodic.write({ kind:'perception', tick: working.tick, traceId: p.traceId,
        summary: p.kind, detail: p.payload, salience: sal, suspicious: p.suspicious, channel: p.channel });
  }
  // DECIDE
  const goal = goals.arbitrate({ perceptions, working });
  if (!goal) return;
  working.activeGoalId = goal.id; goal.lastScheduledAt = Date.now();
  const plan = await goals.plan(goal, { perceptions, working, brain });
  if (plan.offline) { goals.pause(goal.id, 'brain-offline'); return; }
  if (plan.done || !plan.action) { if (plan.done) goals.complete(goal.id); return; }
  goal.spent.tokens += plan.spentTokens || 0;
  // ACT
  const verdict = leash.check(plan.action, { goalId: goal.id, grants: goal.grants });
  if (!verdict.allow) {
    if (verdict.requireConfirm) bus.emit('action.confirm', { action: plan.action, tier: verdict.tier, goalId: goal.id });
    return;
  }
  cx.inFlightDispatch = new AbortController();
  const result = await effectors.dispatch(plan.action,
    { signal: cx.inFlightDispatch.signal, goalId: goal.id, stepIndex: plan.stepIndex });
  cx.inFlightDispatch = null;
  await memory.episodic.write({ kind:'action', tick: working.tick, goalId: goal.id,
    summary: `${plan.action.tool} (${result.ok ? 'ok' : 'fail'})`, detail: plan.action,
    tier: verdict.tier, outcome: result.ok ? 'ok' : 'fail', tokensSpent: plan.spentTokens || 0 });
  // REFLECT
  if (working.tick % cx.cfg.REFLECT_EVERY === 0)
    await memory.episodic.write({ kind:'reflection', tick: working.tick, summary:`progress goal ${goal.id}` });
  if (working.tick % cx.cfg.CONSOLIDATE_EVERY === 0) await memory.consolidate();
}

const W = { drive:0.4, priority:0.25, urgency:0.15, salience:0.2, pressure:0.3, sticky:0.15, aging:0.1 };
const AGING_HORIZON_MS = 10 * 60 * 1000;
function score(goal, ctx, currentId) {
  const d = ctx.drives[goal.drive].baseWeight;
  const urg = goal.budget.deadline ? Math.min(1, 1 / Math.max(1, (goal.budget.deadline - Date.now()) / 60000)) : 0;
  const sal = ctxSalience(goal, ctx.perceptions);
  const press = goal.budget.tokens ? goal.spent.tokens / goal.budget.tokens : 0;
  const sticky = goal.id === currentId ? W.sticky : 0;                     // anti-thrash
  const aging = Math.min(1, (Date.now() - (goal.lastScheduledAt || 0)) / AGING_HORIZON_MS); // anti-starvation
  return W.drive*d + W.priority*goal.priority + W.urgency*urg + W.salience*sal
       - W.pressure*press + sticky + W.aging*aging;
}
function arbitrate(goals, ctx, currentId) {
  const live = goals.filter(g => g.status === 'active' || g.status === 'proposed');
  if (!live.length) return null;
  return live.map(g => ({ g, s: score(g, ctx, currentId) })).sort((a,b) => b.s - a.s)[0].g;
}

function createLeash({ tiers, boundaries, audit, config }) {
  function check(action, goalCtx) {
    const b = boundaries.denies(action);                     // boundaries.md hard rules FIRST
    if (b) return audited({ allow:false, requireConfirm:false, tier:tiers.tierOf(action),
                            reason:`boundary:${b}`, boundaryHit:b }, action, goalCtx);
    const tier = tiers.tierOf(action);
    if (tier <= config.AUTONOMOUS_MAX_TIER)
      return audited({ allow:true, requireConfirm:false, tier, reason:'auto' }, action, goalCtx);
    if (tier === 3) {
      const g = goalCtx.grants && goalCtx.grants['3'];
      return audited(g ? { allow:true,  requireConfirm:false, tier, reason:'granted' }
                       : { allow:false, requireConfirm:true,  tier, reason:'confirm-once' }, action, goalCtx);
    }
    return audited({ allow:false, requireConfirm:true, tier:4, reason:'always-confirm' }, action, goalCtx);
  }
  function audited(v, action, goalCtx) {
    try { audit.append({ tool:action.tool, args:redact(action.args), tier:v.tier,
      decision: v.allow ? 'allow' : (v.requireConfirm ? 'confirm' : 'deny'),
      actor:'cortex', reason:v.reason, goalId:goalCtx.goalId, boundaryHit:v.boundaryHit || null }); }
    catch (err) { if (v.tier >= 3) return { allow:false, requireConfirm:false, tier:v.tier,
      reason:'audit-unwritable-failclosed' }; }              // fail-closed for T≥3
    return v;
  }
  return { check };
}

const crypto = require('crypto');
const sha = (s) => crypto.createHash('sha256').update(s).digest('hex');
function createAudit({ file, appendLine, readLastLine }) {
  let prev = null;                                           // rehydrated from last line at boot
  return {
    init() { const last = readLastLine(file()); prev = last ? JSON.parse(last).h : 'genesis'; },
    append(rec) {
      const body = { v:1, ts: Date.now(), ...rec, prev };
      const h = sha(JSON.stringify(body));
      appendLine(file(), { ...body, h });
      prev = h;
    },
    verify(lines) {                                          // walk chain; any break = tamper
      let p = 'genesis';
      for (const l of lines) {
        const { h, ...body } = JSON.parse(l);
        if (body.prev !== p || sha(JSON.stringify(body)) !== h) return { ok:false, at:body.ts };
        p = h;
      }
      return { ok:true };
    },
  };
}

function createBreaker({ failThreshold=3, windowMs=30000, openMs=15000, maxOpenMs=300000, bus, target, now }) {
  let state='CLOSED', fails=[], openedAt=0, cool=openMs;
  const clock = now || (() => Number(process.hrtime.bigint() / 1000000n));  // monotonic ms
  return {
    allow() { if (state==='OPEN' && clock()-openedAt >= cool) state='HALF_OPEN'; return state!=='OPEN'; },
    record(ok) {
      if (ok) { if (state==='HALF_OPEN') { state='CLOSED'; cool=openMs; } fails=[]; return; }
      const t = clock(); fails = fails.filter(x => t-x < windowMs); fails.push(t);
      if (state==='HALF_OPEN') { state='OPEN'; openedAt=t; cool=Math.min(maxOpenMs, cool*2);
        bus.emit('health.breaker.open', { target, cool }); }
      else if (fails.length >= failThreshold) { state='OPEN'; openedAt=t;
        bus.emit('health.breaker.open', { target }); }
    },
    state: () => state,
  };
}

src/core/immune/leases.js — the stall-vs-slow disambiguator:



function createLeases({ now }) {
  const clock = now || (() => Number(process.hrtime.bigint() / 1000000n));
  const active = new Map();                    // key → {expiresAt, extend()}
  return {
    acquire(key, ttlMs) {
      const l = { key, expiresAt: clock() + ttlMs,
                  extend: (ms) => { l.expiresAt = clock() + ms; },
                  release: () => active.delete(key) };
      active.set(key, l); return l;
    },
    anyActive:  () => [...active.values()].some(l => l.expiresAt > clock()),
    anyExpired: () => [...active.values()].some(l => l.expiresAt <= clock()),
  };
}
module.exports = { createLeases };

function createWatchdog({ cortex, goals, working, leases, bus, config }) {
  let restarting = false;
  const timer = setInterval(async () => {
    if (restarting) return;
    const stale = Date.now() - cortex.lastTickAt > config.STALL_MS;
    const legitimatelyBusy = leases.anyActive() && !leases.anyExpired();
    if (!stale || legitimatelyBusy) return;    // slow ≠ stalled when a lease is heartbeating
    restarting = true;
    bus.emit('health.anomaly', { kind:'cortex-stall', lastTickAt: cortex.lastTickAt });
    if (cortex.inFlightDispatch) {             // never hard-kill mid side-effect
      cortex.inFlightDispatch.abort();
      await sleep(config.GRACE_MS || 500);
    }
    cortex.stopTimerOnly();                    // clearInterval; WorkingMemory UNTOUCHED
    const g = goals.get(working.activeGoalId);
    if (g && g.status === 'active') goals.pause(g.id, 'cortex-restart');    // no fake resume
    cortex.start();                            // generation bump → stale loop inert
    restarting = false;
  }, config.WATCHDOG_MS);
  timer.unref();
  return { stop: () => clearInterval(timer) };
}

const crypto = require('crypto');
const idemKeyOf = (goalId, stepIndex, tool, args) =>
  crypto.createHash('sha256').update(`${goalId}|${stepIndex}|${tool}|${JSON.stringify(args)}`).digest('hex');
function effectorFromTool(tool, { tierOf, breaker, leases, config }) {
  return {
    id: tool.name, tier: tierOf(tool.name, tool.danger, tool.dangerWhen),
    describe: () => ({ name: tool.name, description: tool.description, params: tool.params }),
    validate: (p) => { for (const k of Object.keys(tool.params || {}))
      if (tool.params[k].required && p[k] == null) return { ok:false, reason:`missing ${k}` };
      return { ok:true }; },
    async invoke(p, ctx) {
      if (config.MYTHOS_DRY_RUN && this.tier >= 1) return { ok:true, result:'dry-run', dryRun:true };
      if (this.tier >= 1) {                                       // idempotency across crashes
        const key = idemKeyOf(ctx.goalId, ctx.stepIndex, tool.name, p);
        const prior = ctx.goal && ctx.goal.completedIdemKeys.find(k => k.key === key);
        if (prior) return { ...prior.result, replayed: true };    // never re-execute
        ctx.idemKey = key;
      }
      if (breaker && !breaker.allow()) return { ok:false, result:'circuit-open' };
      const lease = leases.acquire(tool.name, 2 * config.MYTHOS_TICK_MS);
      try {
        const r = await tool.fn(p, { ...ctx, extendLease: (ms) => lease.extend(ms) });
        const ok = !!(r && r.ok !== false);
        breaker && breaker.record(ok);
        const out = { ok, result: r && r.result, uiActions: (r && r.uiActions) || [], needsResult: !!(r && r.needs_result) };
        if (ctx.idemKey && ctx.goal) ctx.goal.completedIdemKeys.push({ key: ctx.idemKey, result: out });
        return out;
      }
      catch (err) { breaker && breaker.record(false); return { ok:false, result: err.message }; }
      finally { lease.release(); }
    },
  };
}

Autonomy wiring summary (why it is always autonomous, not reactive)

The loop runs without input. setInterval(TICK_MS) fires forever; input is one perception channel among five. Zero perceptions → the tick still executes (idle path, zero cost).
Goals come from within. Curiosity and maintenance drives propose goals during idle periods (rate-limited); the entity initiates work without being asked.
Decisions are budgeted, not prompted. The arbiter picks the top goal every tick (aging guarantees everything eventually runs); the planner advances it within token/action budgets; no human turn-taking gates progress.
Governance replaces the human-in-the-loop for safe actions. Tiers 0–2 execute autonomously; only 3/4 pause. Autonomy is bounded by policy, not by approval-for-everything.
It heals itself. Breakers, lease watchdog, healer playbooks, and WAL crash recovery keep the loop alive across failures — the defining property of an entity versus an agent.
It cannot be steered by its senses. Perception content is fenced data; directive-looking payloads are flagged and tier-capped; boundaries are human-owned, checksummed, and unwritable by the entity itself.
Cost is bounded so always-on is affordable. Idle ticks never call Brain; breakers stop hammering dead providers; per-goal budgets cap spend; consolidation is throttled.
